GYM TIMER PWA

GitHub Pagesで公開する方法:
1. GitHubに新しいリポジトリを作成
2. このフォルダのファイルをリポジトリのルートにアップロード
3. Settings > Pages > Build and deployment > Deploy from a branch を選択し、main / (root) を保存
4. 発行された https://... のURLをiPhoneのSafariで開く
5. 共有 > ホーム画面に追加 を選択

※ file:// ではService Workerが動作しません。HTTPSで公開してください。
※ iPhoneの画面ロック中や消音モードでは通知音が保証されません。
