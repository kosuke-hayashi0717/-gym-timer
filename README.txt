GYM TIMER オフライン対応版

1. ZIPを展開して中身の全ファイルをGitHubリポジトリのルートへアップロードしてください。
2. GitHub Pagesのデプロイ完了後、オンラインで公開URLをSafariで開いてください。
3. iPhoneでは共有 → ホーム画面に追加を選び、ホーム画面から一度起動してください。
4. 数秒待ってから機内モードでアプリを再起動し、タイマーと音を確認してください。

注：初回はネット接続が必要です。iOSのストレージ管理等でキャッシュが削除されると再取得が必要です。画面ロック中やバックグラウンドでの通知音は保証されません。
更新時はService Workerのキャッシュ名を変更することで新しいバージョンに切り替わります。
